A collection of **Full Stack Development Lab 3 tasks** completed using HTML, CSS, and Bootstrap 5.

## 🚀 What's Included

### 📌 Bootstrap Conversion

The existing interfaces from **Lab 2** were recreated using **Bootstrap 5**, focusing on:

* Bootstrap Grid System
* Responsive layouts
* Navbar
* Cards
* Buttons
* Forms
* Bootstrap utilities
* Responsive components

The goal was to understand how previously built HTML/CSS layouts can be converted into responsive Bootstrap-based interfaces while keeping custom CSS to a minimum.

---

## 🛍️ E-Commerce Store

A clean, minimalist **eyewear e-commerce website (VVANS)** built with Bootstrap 5.

### Features

* Responsive Bootstrap Navbar
* Hero Section
* Product Listing
* Product Cards
* Customer Reviews
* Login Modal
* Signup Modal
* Side Shopping Cart using Bootstrap Offcanvas
* Static Cart Editing UI
* Checkout Section
* Responsive Design

### 🛒 Shopping Cart

The cart uses Bootstrap's **Offcanvas** component and opens from the right side of the screen.

> Cart functionality is currently static. JavaScript-based functionality will be added in the upcoming JavaScript lab.

### 🔐 Authentication

Login and Signup are implemented as Bootstrap **Modals**.

No custom JavaScript authentication has been added.
